## команды для докера
# docker ps -a - показывает какие докеры есть
# docker stop $(docker ps -q) останавливет запущеные докеры
# docker images - показывает образы

- Хост - основная операционная система, в которой установлен Distrobox
- Контейнер - изолированное программное пространство (Sandbox, песочница), в котором можно создавать особое программное окружение для работы приложений. Контйенер представляет собой подобие виртуальной машины. В основном в контейнерах работают различные операционные системы на базе Linux. Контейнеры слабо взаимодействуют в хостом (основной ОС).
- Виртуальная машина - это программная среда, которая эмулирует работу полноценного компьютера: у неё есть свой процессор, оперативная память, диск, сетевая карта и т. д. Внутри ВМ можно установить операционную систему (например, Linux в Windows или наоборот) и запускать приложения так, будто они работают на реальном железе.
- Гостевая ОС, гость - операционная система, установленная в контейнер.



## Запуск Ollama в контейнере
 
Получить ollama:
```shell
docker run -d -v ollama_data:/root/.ollama -p 11434:11434 --name ollama ollama/ollama
```
```shell
docker exec -it ollama ollama run phi4
```
установить модель phi4:
```shell
ollama run phi4
```
выйти из командного режима нейросети:
```shell
/exit
```
и
```shell
/bye
```

# Основы редактирования текста

## Курсор
- `Home` - в начало строки
- `End` - в конец строки
- `PgUp` - в начало документа
- `PgDown` - в конец документа

- `Ctrl+>` перемещение курсора по словам вправо
- `Ctrl+<` перемещение курсора по словам влево

## Сохранение

- `Ctrl+S` - сохранение всего документа
- `Ctrl+Z` - отмена последнего действия
- `Ctrl+Y` - возврат последнего действия

## Выделение

- `Ctrl+A` - выделить всё
- `Ctrl+>` - выделение по символу вправо
- `Ctrl+<` - выделение по символу влево
- `Shift+^` - выделение строк вверх
- `Shift+v` - выделение строк вниз

## Многострочное редактирование

- `Ctrl+Shift+\` - вертикальное ведение вверх
- `Ctrl+Shift+v` - вертикальное ведение вверх

## Табуляция

`Tab` - отступ на 2 или 4 пробела
